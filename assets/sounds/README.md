
# Audio assets

Masukkan efek suara game ke folder ini saat sudah tersedia.

Contoh nama file yang disarankan:

```text
build.wav          # Saat membangun lantai
cannon.wav         # Tembakan Cannon
tesla.wav          # Serangan Tesla
freeze.wav         # Efek Freeze
rocket.wav         # Ledakan Roket
laser.wav          # Serangan Laser
fusion.wav         # Fusion Beam
wave_win.wav       # Wave berhasil diselesaikan
base_hit.wav       # Base terkena damage
```

Gunakan format `.wav` ketika masih mengedit audio, lalu pertimbangkan `.ogg` atau `.mp3` untuk ukuran file lebih kecil. Pastikan lisensi audio memperbolehkan penggunaan dalam proyek game.
